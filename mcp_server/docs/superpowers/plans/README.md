# docs/superpowers/plans/

One step-by-step implementation plan per feature, each with a checkbox
(`- [ ]`) task list meant to be executed by
`superpowers:subagent-driven-development` or
`superpowers:executing-plans`, task-by-task. Each plan names its paired
spec under `../specs/` in its own header.

- `2026-08-23-capability-restructure.md` - the `src/configs/`+
  `src/secrets/`+`src/data/` restructure, per-capability READMEs, and
  the `config_capabilities.json` enable/disable toggle.

See [`../specs/README.md`](../specs/README.md) for the design spec this
implements.
