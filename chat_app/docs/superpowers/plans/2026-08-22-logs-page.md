# Logs Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/logs` page with Logs and Errors tabs (each gated by its own permission, page visible if either is held), a `LogEntry` DB-backed logging subsystem, automatic unhandled-exception capture, and instrumentation of existing auth/admin/account actions so the page shows real data.

**Architecture:** One new `LogEntry` model backs both tabs (`kind="action"` for the Logs tab, `kind="error"` for the Errors tab; `account_id=NULL` means "server"). A new `log_service.py` exposes `log_action`/`log_error`/`list_entries`. Existing routes call `log_action` explicitly on their success paths; a new generic `run.py` exception handler calls `log_error` automatically for any unhandled exception. `pages/__index__.py`'s nav-visibility check gains "any of a tuple of permissions" support so the Logs page (which needs `PAGE_PERMISSION = ("logs.view", "logs.errors.view")`) shows up for an account holding either one.

**Tech Stack:** Flask, Flask-SQLAlchemy, Flask-Login, Jinja2, pytest (existing stack — no new dependencies).

**Spec:** [docs/superpowers/specs/2026-08-22-logs-page-design.md](../specs/2026-08-22-logs-page-design.md)

## Global Constraints

- Two permissions: `logs.view` (Logs tab), `logs.errors.view` (Errors tab) — registered via `authz.register_permission()`.
- `LogEntry.account_id = NULL` means "server"; there is no "all accounts" filter option.
- Errors are captured **only** via the automatic unhandled-exception handler — no manual `log_error(...)` call sites anywhere else.
- Actions are logged only on the **success** path of each call site — validation failures/no-ops are not logged.
- Row cap: `list_entries(..., limit=200)` — no pagination beyond the cap.
- The Errors-tab dropdown and the Logs-tab dropdown both list **every** account (not just accounts with existing entries), Server first/default.
- `SecurityEvent` is untouched — stays scoped to its existing auth-specific events.
- Follow existing page-folder conventions exactly: `template_folder="."`, `static_folder="."`, `static_url_path="/static"`, a `README.md`, `PAGE_PERMISSION`/`PAGE_DESCRIPTION` module constants.

```python
from src.models import Account, LogEntry


def log_action(db_session, account: Account, source: str, message: str, details: str | None = None) -> LogEntry:
    entry = LogEntry(
        kind="action",
        account_id=account.id,
        source=source,
        message=message,
        details=details,
    )
    db_session.add(entry)
    db_session.commit()
    return entry


def log_error(
    db_session, account: Account | None, source: str, message: str, details: str | None = None
) -> LogEntry:
    entry = LogEntry(
        kind="error",
        account_id=account.id if account else None,
        source=source,
        message=message,
        details=details,
    )
    db_session.add(entry)
    db_session.commit()
    return entry


def list_entries(db_session, kind: str, account_id: int | None = None, limit: int = 200) -> list[LogEntry]:
    query = db_session.query(LogEntry).filter_by(kind=kind)
    if account_id is None:
        query = query.filter(LogEntry.account_id.is_(None))
    else:
        query = query.filter(LogEntry.account_id == account_id)
    return query.order_by(LogEntry.created_at.desc()).limit(limit).all()
```

```python
            email=f"{username}@example.com",
            password_hash=generate_password_hash("pw"),

        if permission_names:
```

```python
PAGE_PERMISSION = ("logs.view", "logs.errors.view")
PAGE_DESCRIPTION = "View server and per-account activity and error logs."

register_permission("logs.view")
register_permission("logs.errors.view")

_ROW_LIMIT = 200


def _resolve_actor(raw_value: str) -> int | None:
    if raw_value == "server":
        return None
    try:
        return int(raw_value)
    except ValueError:
        return None


@blueprint.route("/")
@require_login()
def index():
    can_view_logs = has_permission(current_user, "logs.view")
    can_view_errors = has_permission(current_user, "logs.errors.view")
    if not (can_view_logs or can_view_errors):
        abort(403)

    accounts = db.session.query(Account).order_by(Account.username).all()
    active_tab = request.args.get("tab", "logs" if can_view_logs else "errors")
    logs_actor = request.args.get("logs_actor", "server")
    errors_actor = request.args.get("errors_actor", "server")

    log_entries = None
    error_entries = None
    if can_view_logs:
        log_entries = log_service.list_entries(
            db.session, "action", _resolve_actor(logs_actor), limit=_ROW_LIMIT
        )
    if can_view_errors:
        error_entries = log_service.list_entries(
            db.session, "error", _resolve_actor(errors_actor), limit=_ROW_LIMIT
        )

    return render_template(
        "view.html",
        can_view_logs=can_view_logs,
        can_view_errors=can_view_errors,
        active_tab=active_tab,
        accounts=accounts,
        logs_actor=logs_actor,
        errors_actor=errors_actor,
        log_entries=log_entries,
```
