# docs/superpowers/

Specs and implementation plans produced by the `superpowers` skill workflow
before each feature was built:

- **[`specs/`](specs/README.md)** - one design spec per feature: goals,
  non-goals, architecture.
- **[`plans/`](plans/README.md)** - one step-by-step implementation plan per
  feature (or per phase, for the multi-phase AuthTemplate build), meant to be
  executed task-by-task by an agentic worker.

These are point-in-time documents, not maintained after the feature ships -
if a spec or plan disagrees with the code, the code (and the relevant
folder's own README) wins.
