# docs/superpowers/

Specs and implementation plans produced by the `superpowers` skill
workflow before a feature was built:

- **[`specs/`](specs/README.md)** - one design spec per feature: goals,
  motivation, architecture.
- **[`plans/`](plans/README.md)** - one step-by-step implementation plan
  per feature, meant to be executed task-by-task by an agentic worker.

These are point-in-time documents, not maintained after the feature
ships - if a spec or plan disagrees with the code, the code (and the
relevant capability's own README) wins.
